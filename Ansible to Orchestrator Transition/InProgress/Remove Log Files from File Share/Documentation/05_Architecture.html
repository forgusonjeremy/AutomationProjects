What the drawing is asserting

Where the credentials are

Nowhere on the wire. The Active Directory plug-in authenticates with the account stored against each domain endpoint, and the PowerShell plug-in with the account stored against the host. No workflow input accepts a username or a password, which is what retired the playbooks' WinRM_username and WinRM_password variables along with the hop that needed them.

Why the domain is never asked for

The operator picks a group from a tree, so the group object arrives already bound to its endpoint. For scheduled runs, the DC= components of the group's distinguishedName name the domain, and the endpoint follows from that. In both paths the domain is derived, never entered — so it cannot disagree with the group.

The second hop

Orchestrator connects to the PowerShell host; the host then reaches the servers and the share on its own behalf. That crossing needs Kerberos constrained delegation. Ansible never had this problem because it connected to each server directly — it is the one genuinely new piece of infrastructure in this design, so prove it before anything else.

The script's short life

A script is held in Orchestrator as a Resource Element, written to %TEMP%\Orchestrator on the host, run by path, then deleted. Nothing is pre-staged and nothing is left behind to drift out of step with the version Orchestrator holds.

Why the transfer is manual today

Phase 1 delivers ten files that are pasted into Orchestrator once. Automating the transfer means a pipeline that authenticates to the Orchestrator API, and it needs its own service account, its own secret handling, and a rollback story. That is a project in its own right, and it does not block the workflows from running.

What automation would buy

Today nothing compares what is deployed against what is committed, so the two can differ silently and a fix made in Orchestrator can be lost at the next paste. A pipeline makes the repository authoritative: every change is reviewed, versioned and traceable, and redeploying is a merge rather than an afternoon.
